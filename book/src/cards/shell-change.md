# Shell change card

In step mode, edits wait for you, but a shell command runs straight away. So after a `Bash` call in a step-mode project, aq compares the project's files before and after. If the command changed anything, the change becomes a card.

## Keys

| Key | What it does |
|---|---|
| `y` | keep the change |
| `u` | ask Claude to undo it |
| `j` `k` | move by line |
| `]c` `[c` | next or previous change |
| `H` `L` or `Tab` | previous or next file |
| `v` | split or unified view |
| `f` | hide or show the file list |
